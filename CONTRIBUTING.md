# Contributing

Run `npm test` and `npm run check` before proposing a change. Keep every editor
operation inside the public allowlisted contract and add validation tests for
new schema behavior.

Do not submit workbooks, credentials, signing keys, generated office-suite
source trees, binaries, or machine-local paths. Branding patches must remain
small and reviewable, and must not obscure upstream license notices.

Security reports should follow `SECURITY.md` rather than a public issue.
