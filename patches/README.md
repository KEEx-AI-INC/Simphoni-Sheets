# Upstream patch set

Reviewed Collabora Online and LibreOffice source patches belong here as ordered,
numbered patch files. Each binary build receipt must record the filename and
SHA-256 digest of every applied patch.

The initial source beta has no upstream code patches: branding is supplied by
the public tokens, library UI, and allowlisted editor extensions in this
repository. A native or hosted artifact must remain marked `unbuilt` until any
upstream branding changes it needs are added here and reviewed.
