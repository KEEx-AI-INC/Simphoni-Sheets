# Security policy

SimphoniSheets public beta is security-sensitive because it parses office
archives and bridges an AI proposal to a document editor. Please report a
suspected vulnerability privately through the security-advisory feature of the
GitHub repository. Do not include customer workbooks, prompts, tokens, or
credentials in a report.

Supported public-beta releases are the versions referenced by the current
signed artifact lock. Unbuilt source snapshots and superseded locks are not
production releases.
