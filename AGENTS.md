# SimphoniSheets Agent Guide

- Treat this repository as the canonical owner of Sheets contracts, editor
  extensions, branding patches, and reviewed runtime artifacts.
- Keep generated Collabora/LibreOffice source trees, images, packages, logs,
  signing keys, and workbooks out of git.
- Never add arbitrary UNO, macro, Python, or shell execution to a browser or
  model-facing interface.
- Keep hosted and offline proposal validation behavior identical.
- Do not place model weights, Firebase credentials, signing private keys, or
  machine-local absolute paths in artifacts.
- Preserve upstream MPL/LGPL notices and publish corresponding modified source.
